#### [Posted - Socialweb](https://github.com/WeFake123/Posted-socialweb)
Una mini red social dinámica y en tiempo real.
* **Frontend:** React + Vite + Bootstrap, Socket.IO Client.
* **Características:** Sistema de posts interactivos, chats y respuestas en vivo (`>>serial`), integración con Cloudinary para subida de imágenes y notificaciones instantáneas mediante `authorHash` almacenado en el navegador.

Una API robusta construida con las últimas versiones de **.NET** (ASP.NET Core / Entity Framework).
